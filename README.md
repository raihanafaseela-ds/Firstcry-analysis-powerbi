## 🛍️ FirstCry Return & Refund Analysis (Power BI)

## 📌 Project Overview
This project analyzes return and refund patterns in FirstCry data to identify trends and improve business decisions.

---

## 📊 Dataset
The dataset contains order details, return status, refund amounts, and customer-related information.

---

## 📈 Key Insights
- High return rates observed in certain product categories  
- Refund patterns vary across regions  
- Identified factors contributing to returns  

---

## 🛠️ Tools Used
- Power BI

---

## 💡 Features
- Interactive dashboard  
- KPI tracking  
- Category-wise analysis  
- Trend visualization  

---

## 📁 Project File
Power BI file (.pbix) is included in this repository.

---

## 🚀 Conclusion
This analysis helps in understanding return behavior and improving product and logistics strategies.
